# 阅读器

## 内容与语言

阅读器使用语义化文章结构展示单话正文，支持原文与译文切换。译文保存在单话 JSON 的 `translation` 字段中，原文字段不被覆盖。

原文使用 Noto Serif JP，中文译文使用 Noto Serif SC。阅读器导航、设置、按钮和正文都使用衬线字体，保持书页风格。

## 阅读设置

设置保存在当前浏览器的 localStorage，不写入服务端。可调整字号、字距、行距、段距、阅读背景、正文字体颜色和人物信息下划线提示开关。

阅读器自定义纸色和全站深浅主题相互独立。退出阅读器后恢复普通页面的浏览器外观和主题色。

## 人物提示

阅读器使用初始化材料中的角色原名、中文名和别名进行轻量匹配，支持全名和常见短名。桌面端鼠标悬浮显示简介，移动端点击显示简介，不把有歧义的普通称呼强行标记。

## Safari 阅读器模式

正文采用 `article`、标题、段落和章节语义结构，工具栏与正文分离，并保留打印样式。最终是否出现 Safari 阅读器入口由 Safari 判断，网页不能强制开启该模式。

## 阅读状态

成功打开正文会记录为在读。滑到底部后点击下一话，会先将当前话标记为已读再跳转。原文和译文共用同一条状态记录。
