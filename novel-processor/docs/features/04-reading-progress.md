# 阅读进度

## 状态

| 状态 | 含义 | 颜色 |
| --- | --- | --- |
| `unread` | 没有阅读记录 | 红色 |
| `reading` | 已打开但尚未完成 | 黄色 |
| `read` | 已完成阅读 | 绿色 |

没有记录的 episode 按未读处理。阅读状态不区分原文和译文。

## 自动记录

1. 成功进入一话正文时写入 `reading`；
2. 只有在正文末尾点击下一话时才写入 `read`；
3. 最后一话可以点击“标记已读并返回目录”；
4. 写入失败会保留当前阅读页面并显示重试入口。

## 手动编辑

详情页目录支持单话、章节、全书以及自定义起止话号范围。范围使用事务写入，范围外的状态不受影响。

临时“折叠已读”视图只改变目录显示，不改变数据库中的章节或阅读记录。

## SQLite

阅读记录位于 `episode_reading` 表，主键为 `(novel_id, episode_index)`，包含状态和更新时间。作品永久删除时由外键级联清理；移入回收站、恢复、更新目录和下载校准不会清空记录。

## 相关接口

- `GET /api/library/:site/:novelId/reading`
- `PUT /api/library/:site/:novelId/reading`
- `GET /api/library` 返回作品阅读汇总
