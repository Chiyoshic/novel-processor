# 书架、作品管理与回收站

## 书架

书架从 SQLite 索引查询作品，支持标题或作者搜索、站点/连载状态/题材/标签筛选、下载进度筛选、阅读进度筛选，以及最近更新、导入时间、标题和进度排序。

下载进度和阅读进度是两套独立状态。作品全部下载不等于已读完。

## 作品卡片

卡片展示作品标题、作者、连载状态、话数、章节数、字数、下载数量、下载百分比、已读数量、已读百分比和按话分布的阅读状态条。

如果存在在读话，继续阅读会进入话序最大的在读话；没有在读话时从第一话开始。

## 作品详情

详情页负责显示作品元数据和目录，更新目录，批量/按章/逐话下载，显示下载/阅读/翻译状态图标，编辑阅读状态，进入阅读器和 AI 翻译页面，以及管理回收站。

目录中的章节分组只影响展示和批量操作，不改变正文文件的 episode 编号。

## 回收站

移入回收站是软删除：作品从正常书架隐藏，目录、正文、译文和磁盘文件保留，可以恢复，SQLite 保留回收站状态。

永久删除或清空回收站才会删除文件和数据库记录，操作不可撤销。删除前应备份整个 `data/`。

## 重建索引

首页的重建索引会扫描 `data/novels` 和 `data/episodes`，重新同步作品、章节、话和下载标记。它不会重建或恢复用户账号、模型配置、翻译材料、翻译任务状态、阅读记录或回收站状态。这些数据保存在 SQLite 中。
