# 抓取中途取消

书本详情页抓取时显示“取消抓取”。取消发到后端，而非仅断开浏览器请求；刷新或重新进入详情页后，可从任务状态继续取消。已保存的正文和译文保持不变，取消不会清空已下载内容。

- `POST /api/library/:site/:novelId/fetch/stop`：标记 stopping，并 abort 对应书本抓取任务。重复调用安全，无任务返回 job:null。
- `/status` 的 job 增加 `stopping`、`cancelled`；抓取原请求正常结束时返回 `cancelled`，不把取消的话数当作失败。
- 停止后不再调度后续话，网络请求、并发名额等待、请求节奏等待与重试退避均可取消；进行中的原子写盘允许完成，避免留下半个文件。
- 每话落盘后增量同步 SQLite；取消结束仍校准磁盘索引并清理 activeIndices 与 controller。清理完成前任务仍锁定同一本书，不接受新抓取。
- 抓取进行中阻止删除同书、重建索引，以免在写盘时清理数据。

顶部新增“继续阅读”，使用 play.fill.svg，使用 CompactButton，图标位于文字右侧，胶囊可见高度与同排圆形图标统一为28px，点击区域同为28px；文字11px、播放图标12px，与左侧图标保持一致的可见间距。标准胶囊使用 NormalButton，保留原有主色、透明与小号样式。有在读话时进入话序最大的在读话，否则进入目录首话。

`npm --prefix backend run test:download` 用本地 HTTP、临时 SQLite 和正文目录验证取消响应、停止调度、文件保留、错误归类和再次抓取，不访问外部小说站点。
