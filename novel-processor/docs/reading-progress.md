# 阅读状态

## 状态与自动记录

- 未读 `unread`（红）：默认状态。
- 在读 `reading`（黄）：成功打开一话正文时记录；原文与中文译文共用一条状态，不分别统计。重新进入已读话会改回在读。
- 已读 `read`（绿）：正文末尾进入视口后，点击“下一话”（含键盘下一话）时先保存本话已读，再跳转。只滚动到底不会自动记为已读；未到底就跳转仍是在读。
- 最后一话可使用“标记已读并返回目录”。

自动写入失败会展示错误和重试入口；完成写入失败时不跳走，避免漏记。写入排队执行，避免进入时的在读写入晚于完成写入。切换原文/译文不会重复创建记录。

## 手动修改

阅读器顶部可修改当前话。书本详情目录中，每话旁有状态选择；每章标题旁可批量标记该章（未分章话单独处理）；目录上方可选择状态并点击“应用全书”。这些手动修改允许任意转换，包括重新设为未读，不依赖该话是否下载或翻译。

书架卡片保留下载进度，额外显示已读话数、总话数、已读百分比及红黄绿状态条。状态条从左至右对应首话到末话，每话等宽，不是从左侧填充的进度条。例如第 1、3 话已读而第 2 话未读，则显示绿、红、绿。颜色之外也展示数量、图例和无障碍文本。

## SQLite 与接口

Schema v8 非破坏性增加 `episode_reading`，主键 `(novel_id, episode_index)`，包含 `status`、`updated_at`。未记录的话按未读处理。目录重抓、下载校准、回收站恢复不会重置阅读记录；永久删除作品时由外键级联清理。当前单用户应用全站共用阅读记录。

鉴权沿用所有业务 API：

- `GET /api/library/:site/:novelId/reading`：`{episodes:[{index,status,updatedAt}],total,unread,reading,read,percent,states}`。
- `PUT` 同路径：`{scope:'episode',index,status}`、`{scope:'chapter',chapterIndex,status}`（`null` 指未分章话）或 `{scope:'book',status}`。范围校验后事务写入，返回最新汇总。
- `GET /api/library` 的每个条目新增 `reading` 汇总；`states` 每个字符表示一话，`0/1/2` 分别是未读/在读/已读，按话序排列。分页列表一次批量查询，前端状态条采用合并连续颜色的 CSS 渐变，避免为数千话创建数千个 DOM 节点。

备份时应包含 SQLite（与初始化材料、阅读记录等一起备份），只备份小说 JSON 不能恢复阅读记录。需同时部署前后端，后端启动会迁移数据库；应等待在途翻译结束后再重启后端。

## 验证

`npm --prefix backend run test:reading` 使用临时数据库与本地 HTTP，验证默认状态、各种范围修改、状态条顺序、百分比、重启持久化、迁移、目录同步保护、回收站/永久删除行为及 HTTP 校验，不修改真实数据。
